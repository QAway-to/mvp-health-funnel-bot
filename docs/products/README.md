# Материалы направлений

Здесь лежит то, что покупатель получает по подписке, — разложенное по модулям и
урокам. Это исходник для базы знаний бота и для гайдов приложения: править
нужно здесь, а не в трёх местах сразу.

Собрано из материалов заказчика (папка «feder»). Ничего не добавлено сверх
исходников: где в презентации стоял вопрос без ответа, там в уроке стоит пометка
«требует автора», а не придуманный текст. По этим темам — нагрузка, дыхательные
практики, холодная вода, техника массажа — выдумка приводит человека к травме,
и никакая складность формулировки этого не оправдывает.

## Почему у направлений разная готовность

Дело не в объёме работы, а в том, что было в исходниках.

- **Сон** — тринадцать страниц связного текста: практики, температура, свет,
  тишина, еда, кофеин. Курс собран целиком.
- **Массаж** — пятнадцать слайдов с прозой: виды, приёмы, подготовка,
  противопоказания. Курс собран целиком, это информационное направление.
- **Самомассаж** — есть польза, тайминги по зонам и список из шести приёмов, но
  **нет описания самих приёмов**. Слайды «как правильно делать массаж шеи» и
  «вакуум и правильная техника» — это заголовок и вопросы.
- **Зарядка** — тринадцать слайдов, из них содержательных два. Остальное —
  «зачем и как это делать?». Это план курса, а не курс.

## Что делать дальше

1. Сверить помеченные формулировки в «Сне» и «Массаже» — после этого оба
   направления можно продавать как курсы.
2. Получить от автора недостающее по «Самомассажу» (пять пунктов, список в конце
   файла) — короткие видео закрыли бы почти всё.
3. По «Зарядке» решить: наполнять сейчас или держать в статусе готовящегося
   направления. Файл `zaryadka.md` уже является техническим заданием — вопросы
   каждого слайда перенесены дословно.
4. Перенести готовое в базу знаний бота: сейчас он отвечает только по бегу, а
   бесплатная ступень — общий вход для всех направлений.
