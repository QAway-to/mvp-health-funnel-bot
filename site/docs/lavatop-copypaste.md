# ПРОДУКТ

**Тип:** подписка · **Периодичность:** месяц · **Валюта:** USD

### Название

```
Федерация Здоровья — подписка
```

### Короткое описание

```
Шесть направлений здоровья, 68 шагов по порядку. Бег, сон, закаливание, привычки, зарядка, массаж.
```

### Полное описание

```
Доступ ко всем направлениям Федерации сразу: бег, сон, закаливание, вредные привычки, зарядка, массаж и самомассаж.

Это не подборка советов, а порядок: что делать, в какой последовательности и в каком объёме, чтобы привычка удержалась дольше двух недель.

Материалы приходят в Telegram-бота и разложены по шагам. Шаг — это короткий ролик и текст к нему: видео показывает движение, текст показывает меру — дозировку, порядок и чего не делать. Всего 68 шагов.

Здоровье не делится на курсы: сон тянет за собой утро, утро — нагрузку, нагрузка — восстановление. Поэтому доступ сразу ко всему, а браться за направления можно по очереди.

Новые направления открываются подписчикам без доплаты. В работе ещё четыре: еда, тренировки, голодание, похудение.

Отменить подписку можно в любой момент.
```

## Два места, где нужно ваше решение

**«Беру немного людей»** в третьем плане — замените на число. Это обещание,
которое выполняется руками: еженедельный разбор видео и личный чат. Сколько
человек тянете одновременно?

**Валюта — USD**, как в боте и на сайте. Касса принимает либо одну валюту,
либо сразу три. Нужны рубли и евро — назовите числа, поставлю все три.
