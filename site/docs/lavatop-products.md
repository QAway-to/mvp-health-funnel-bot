# LavaTop: три карточки подписки

Готовые тексты для кабинета. Копируйте блоками — сочинять при заполнении
нечего.

**Зачем это, если оплата уже есть в боте.** Telegram Stars работают только
внутри Telegram и только если у человека есть звёзды. LavaTop принимает карту
у кого угодно. Это не замена, а вторая дверь к тому же самому доступу.

**Продукт один — подписка на все шесть направлений.** Три карточки ниже это не
три курса, а три уровня одной подписки. Материалы на всех уровнях одинаковые и
полные; отличается только то, насколько плотно автор рядом. Это принципиально:
если подать «Базу» как урезанный продукт, её перестают покупать.

Бенефиты дословно те же, что человек видит в боте и на сайте. Это не для
красоты: цена на кнопке уже однажды разошлась со счётом, и стоило это доверия.

## Общие настройки для всех трёх

| Поле | Значение |
| --- | --- |
| Тип | Подписка с автопродлением |
| Период | 1 месяц |
| Валюта | USD — как в боте и на сайте |
| Комиссия платформы | 8% с входящих, учесть при расчёте выручки |
| Что открывается после оплаты | Доступ в Telegram-боте |

**Про валюты.** API кассы принимает цену либо в одной валюте, либо сразу в
трёх (RUB, USD, EUR) — промежуточного нет. Ставлю USD: так совпадает с ботом и
сайтом, и нигде не появится вторая цена, которую придётся держать в голове.
Нужны рубли и евро — назовите свои числа, поставлю все три разом.

## Карточка 1. База — $9 в месяц

**Название**

```
Федерация Здоровья — База
```

**Короткое описание**

```
Все шесть направлений целиком, 68 шагов по порядку. Для тех, кто готов идти сам.
```

**Полное описание**

```
Доступ ко всем направлениям Федерации сразу: бег, сон, закаливание, вредные привычки, зарядка, массаж и самомассаж.

Это не подборка советов, а порядок: что делать, в какой последовательности и в каком объёме, чтобы привычка удержалась дольше двух недель.

Материалы приходят в Telegram-бота и разложены по шагам. Шаг — это короткий ролик и текст к нему: видео показывает движение, текст показывает меру — дозировку, порядок и чего не делать. Всего 68 шагов.

Здоровье не делится на курсы: сон тянет за собой утро, утро — нагрузку, нагрузка — восстановление. Поэтому доступ сразу ко всему, а браться за направления можно по очереди.

Новые направления открываются подписчикам без доплаты. В работе ещё четыре: еда, тренировки, голодание, похудение.

Отменить подписку можно в любой момент.
```

**Что входит**

```
Все направления без ограничений
68 шагов: ролик и текст к каждому
Новые темы сразу после выхода
Порядок и дозировки по шагам
Отмена в любой момент
```

## Что за что отвечает

API кассы умеет меньше, чем кажется, и это решает раздел работ:

```
GET   /api/v2/products        — список, только чтение
PATCH /api/v2/products/{id}   — только массив offers
POST  /api/v3/invoice         — счёт
```

Создания продуктов в API **нет**, и название с описанием самого продукта через
него менять нельзя — только читать.

| Что | Кто |
| --- | --- |
| Создать три карточки в кабинете | Вы |
| Название и описание продукта | Вы, копипастой отсюда |
| Названия офферов, описания офферов, цены | Я, через API |
| Сверить, что легло верно | Я, чтением `GET /products` |

Три копипаста — это всё, что осталось ручного.

## Что нужно решить до первой продажи

### Как оплата свяжется с человеком в боте

Главный вопрос, и он не про тексты. Человек платит на странице LavaTop, а
доступ выдаётся в Telegram: связать одно с другим нечем, если ссылка оплаты не
несёт его идентификатор.

1. Бот подставляет в ссылку `chat_id` покупателя.
2. LavaTop возвращает его в уведомлении об оплате.
3. Бот по нему выдаёт доступ — тем же кодом, что и после Stars.

**Проверьте в документации кассы:** принимает ли страница оплаты произвольный
query-параметр и возвращает ли его обратно. Имя параметра идёт в
`site/src/config/site.ts` → `subscription.trackingParam`.

Без этого оплата пройдёт, а доступ придётся выдавать руками по каждому платежу.

### Вебхук

Адрес: `https://mvp-health-funnel-bot.onrender.com/payments/lavatop`
Секрет: переменная `LAVATOP_SECRET` у сервиса и то же значение в кабинете.

Формат уведомления с документацией не сверялся: маршрут пишет первое
уведомление в лог целиком, по нему поля сверяются за пять минут.

### Ссылки оплаты

Как заведёте карточки — пришлите три ссылки. Они идут в конфиг сайта
(`subscription.tiers.base/premium/pro.payUrl`) и в переменную `PURCHASE_URL` у
бота. Кнопки покупки включатся сами.

### Оферта и политика

LavaTop обычно не подключает продажи без них. Адреса идут в
`site/src/config/site.ts` → `links.offer` и `links.privacy`.

## Чего в продукте пока нет — не обещайте этого в карточке

- **Зарядка и массаж** открыты как материалы, а не как курс: в зарядке нет
  перечня упражнений, в массаже — механики приёмов и техники массажа шеи.
- **Роликов** 24 на 68 шагов: сняты бег и сон целиком, остальные курсы идут
  текстом.
- **Голодания и курения** нет вовсе — в подписку они не входят.

Первое и второе на продажу не влияют, если не обещать лишнего. Третье держите
в голове при рекламе: запрос «как поголодать» приведёт человека, которому мы
ничего не дадим.
